## Botões
- **Desfazer:** tira a última bandeira marcada. Use quando errar.
- **Recomeçar:** apaga todas as bandeiras marcadas.
- **Atualizar:** busca os dados agora, sem esperar a atualização automática.
- **Abrir no SquadCalc:** abre o mesmo servidor no site do SquadCalc.

Desfazer e Recomeçar só aparecem depois da primeira bandeira marcada. Quando o servidor troca de layer, o painel zera sozinho.
