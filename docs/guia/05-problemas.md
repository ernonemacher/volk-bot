## Quando algo parece errado
- **Painel pausado:** o servidor está offline, em seed ou saiu da lista. O mapa some até ter partida, mas o menu de servidor fica: dá para trocar de servidor pelo próprio painel.
- **"Já estou atualizando. Aguarde.":** você clicou enquanto o painel se atualizava. O clique não fica na fila: espere terminar e clique de novo.
- **"Você não tem um cargo liberado":** só operadores confirmam bandeiras. Peça o cargo a um admin.
- **O Discord diz que o Volk não respondeu, ou o painel parou de atualizar:** o bot está fora do ar. Avise um admin.
- **Confirmei a bandeira errada:** Desfazer tira a última.
- **Duas bandeiras com o mesmo nome:** algumas layers repetem nomes para lugares diferentes. O keypad no menu diferencia.
- **O painel sumiu ou travou:** ele volta sozinho na próxima atualização. Se não voltar, um admin resolve com `/volk republish`.

-# O Volk não vê o jogo: tickets, capturas e posições não existem em nenhuma fonte pública. Ele só sabe o que vocês confirmam.
